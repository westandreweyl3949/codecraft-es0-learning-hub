## What is Codecraft?

Codecraft gives ESO students a more engaging way to approach computer science. Its educational material is presented through a playful, game-like experience, making Informatica ESO topics feel more interactive than a conventional classroom webpage.

The project runs directly on the web as HTML, allowing it to be opened in a browser and adapted to a range of learning settings. Teachers and students can use it as a straightforward visual resource with a familiar Minecraft-style environment.

## Using Codecraft

## Frequently Asked Questions

**How can I find the newest version?**  
Visit the repository or hosted build link to check for the latest revision, then update your local copy when changes become available.

**Is additional software needed to use Codecraft?**  
No dedicated runtime is needed; a web browser is enough for normal viewing. Running a local server is optional and mainly useful while developing or testing.

**Which files contain the learning content?**  
The HTML files and their associated assets in the project directory contain the page layout, written material, and visual elements.

**How should I troubleshoot missing or incorrect content?**  
Make sure the correct entry file is open, verify that referenced assets exist in the expected locations, and check that the browser supports the features used by the page.
